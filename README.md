# עורך דיוור AutoSuccess

עורך לבאנר העליון ולבלוקים של הדיוור. רץ על השרת הפרטי ונפתח במחשב בכתובת **http://localhost:3230** דרך מנהרה.

## התקנה במחשב (Windows)
1. כפתור ירוק **Code** ← **Download ZIP**.
2. קליק ימני על ה-ZIP ← מאפיינים ← לסמן "בטל חסימה" ← אישור. אחר כך קליק ימני ← "חלץ הכל" לתיקייה קבועה.
3. לחיצה כפולה על **Install-Windows.bat**. אם מופיע "Windows הגן על המחשב שלך": "מידע נוסף" ← "הפעל בכל זאת".
4. בשולחן העבודה יופיע אייקון "עורך דיוור".

להסרה: **Uninstall-Windows.bat**.
